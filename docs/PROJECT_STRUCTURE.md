# Project structure and audit

```text
FOBE-Assets/
├── frontend/                 # Vite HTML, browser source, Node tests
├── FOBE-API/                 # FastAPI, Firestore store, API tests, task scripts
├── api/ handlers/ storage/   # Python synchronizer and SQLite logic
├── scripts/                  # frontend build, IFC indexing, tunnel watcher
├── public/                   # source static files copied to build output
├── config/backend.json       # public runtime endpoint configuration
├── fragments/ ifc-index/ wasm/ worker.mjs  # generated root copies
├── assets/ index.html model-view.html      # generated root Vite output
├── .env.example package.json requirements.txt main.py
└── docs/
```

`frontend/src/api.js` resolves runtime configuration; `FOBE-API/main.py` exposes the API; `main.py` runs synchronization; `storage/` and `handlers/` hold schema and reconciliation; `scripts/build-frontend.mjs` regenerates Pages files; `scripts/watch-tunnel.cjs` validates and publishes tunnel configuration; `scripts/generate-ifc-index.mjs` needs untracked source IFC files.

Root `index.html`, `model-view.html`, `assets/`, `fragments/`, `ifc-index/`, `wasm/`, and `worker.mjs` are deliberately generated by `npm run build`. The public/static counterparts currently match byte-for-byte. Keep them while Pages is served from the root; do not hand edit them. `frontend/test/fixtures/watcher.env` is used by `watch-tunnel.test.cjs` and is required by that test.

Recommended, approval-required future organization: retain current paths until all scripts, Task Scheduler references and Pages settings change; then consider `backend/` for `FOBE-API`, `synchronizer/` for the root Python modules, and a CI/deployment branch for generated root output. Required next artifact: a tracked/sanitized Node-RED flow export. Optional: explicit `logs/` ignore rule after confirming no logs need tracking.

Security/portability: `.env`, Firebase credential patterns, environments, SQLite databases, and `data/` are ignored. Absolute Firebase/database/index paths are machine-specific. Defaults assume FastAPI 8000 and Node-RED 1880. `config/backend.json` is public but contains no secrets. The API has no application authentication; do not expose writes publicly.
